# Atheliêr do Terno

Site institucional da loja em Lavras, MG, preparado para publicação pelo GitHub Pages.

## Conteúdo

- Página inicial com informações da loja e formas de contato.
- Página de ternos com 10 referências para aluguel e 10 para venda.
- Filtros por categoria, cor, medida fictícia e texto.
- Imagens demonstrativas. Estoque e medidas devem ser confirmados com a loja; o caimento pode ser ajustado na prova.

## Publicação

O workflow em `.github/workflows/pages.yml` publica a raiz do repositório no GitHub Pages a cada push em `main` e também permite execução manual pela aba Actions.
